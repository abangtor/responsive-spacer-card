# Responsive Spacer Card

An invisible Lovelace spacer whose height adapts to its rendered width. Set `ratio: 0.17` for a spacer 17% as high as its width, optionally with minimum and maximum pixel limits.

Use **Scale factor** in the visual editor (or `scale_factor` in YAML) to fine-tune the computed gap: `1` unchanged, `1.10` 10% taller, `0.90` 10% shorter. In fill mode, scaling happens after title/padding compensation.
